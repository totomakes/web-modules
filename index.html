How to use one

  1. Open a module and hit Code in the dock — every file has a header comment with the markup and options.
  2. Copy the module's .css / .js next to your page and include them. They auto-initialise.
  3. Add the markup shown in the header, tweak the data-* options or the CSS custom properties.
